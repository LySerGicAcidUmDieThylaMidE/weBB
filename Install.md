# INSTALL.md

## Установка и запуск проекта LudereZone

### Требования

Требования по софту перед запуском:

* Python 3.10 или новее
* MySQL Server 8.0 или новее
* pip

---

## 1. Клонирование проекта

```bash
git clone <адрес_репозитория>
cd LudereZone
```

Либо распакуйте архив проекта в любую папку.

---

## 2. Создание виртуального окружения

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

## 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 4. Создание базы данных

Запустить MySQL и создать базу данных:

```sql
CREATE DATABASE luderezone CHARACTER SET utf8mb4;
```

---

## 5. Настройка подключения

В файле app.py указать параметры подключения к MySQL:

```python
app.config["SQLALCHEMY_DATABASE_URI"] = (
    "mysql+pymysql://ЛОГИН:ПАРОЛЬ@localhost/luderezone"
)
```

где:

* ЛОГИН — имя пользователя MySQL
* ПАРОЛЬ — пароль пользователя MySQL

---

## 6. Инициализация базы данных

При первом запуске автоматически создаются необходимые таблицы.
При необходимости можно удалить старую базу и создать её заново.

---

## 7. Запуск проекта

Из корневой директории выполнить:

```bash
python app.py
```

После успешного запуска сервер будет доступен по адресу:

```text
http://127.0.0.1:5000
```

---

## 8. Использование

На сайте доступны следующие возможности:

* регистрация пользователей;
* авторизация;
* восстановление пароля по секретному слову;
* изменение пароля;
* просмотр каталога игрушек;
* поиск и фильтрация товаров;
* просмотр карточек товаров;
* добавление товаров в корзину;
* управление корзиной;
* добавление товаров в избранное;
---


Изменить порт запуска в app.py либо завершить процесс, использующий данный порт.
