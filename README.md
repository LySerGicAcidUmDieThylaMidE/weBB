# Наименование: LudereZone

## Краткое описание:
LudereZone — это современное веб-приложение для продажи игрушек. Платформа позволяет пользователям просматривать наиболее значимые характеристики для выбора игрушек, фильтровать каталог, добавлять товары в избранное и управлять профилем. Административная панель обеспечивает полное управление ассортиментом.

## Целевая аудитория:
Родители с детьми, молодые пары, подростки.

## Ключевой функционал:
- Каталог с фильтрацией: Просмотр игрушек с фильтрацией по названию, категории, цене и производителю.
- Детальная карточка товара: Отображение характеристик, галереи изображений, краткого описания.
- Личный кабинет: Управление профилем, смена пароля.
- Избранное: Сохранение понравившихся товаров в отдельный список.
- Поиск: Полнотекстовый поиск по названиям и описаниям.
- Аутентификация: Регистрация, вход, восстановление пароля.

## Структура приложения:
- Главная	(/)	Страница с баннерами, списком популярных игрушек и новинок.
- Аутентификация	(/auth/*)	Страницы входа, регистрации, восстановления пароля.
- Каталог	(/catalog) Сетка товаров с фильтрами (по категориям, цене, популярности) и сортировкой.
- Детальная страница	(/catalog/:id) Полная информация об игрушке: фото, характеристики, описание, кнопка "В избранное" и "В корзину".
- Ошибка	(/err)	Страница с выводом ошибки.
- Избранное	(/fav)	Список товаров, которые пользователь отправил "В избранное".
- Личный кабинет	(/prof)	Данные пользователя, избранное, смена пароля.
- Корзина	(/cart)	Просмотр товаров в корзине и общая стоимость.


## Технологический стек:
- Frontend: Фреймворк: React + TypeScript (TypeScript обеспечивает строгую типизацию на фронтенде).
- Роутер: React Router v6 (Стандарт для навигации в React-приложениях).
- State-менеджмент: Redux Toolkit + RTK Query (RTK Query автоматически управляет кэшированием, загрузкой и состоянием ошибок для API запросов).
- Backend: Язык: Python 3.11+ (Современная версия с улучшенной производительностью, поддержкой асинхронности и новыми возможностями типизации).
- Фреймворк: FastAPI (Асинхронный, встроенная валидация через Pydantic, высокая производительность)
- База данных: MySQL

## Страница: Главная (/)
Тип доступа: Публичный  
Основные блоки:  
Шапка: Логотип (LudereZone), навигация (каталог, сравнение), иконка поиска, иконка избранного, иконка пользователя (или кнопка "Войти").  
Hero-блок: Заголовок "Магазин всяких игрушек, а чего тебе ещё надо?".  
Секция "Популярное": 3 категории.  
Динамика: Данные загружаются.  
Секция "Категории": 3-4 крупные картинки (Развивающие, Конструкторы, Мягкие игрушки) с ссылками на каталог с предустановленным фильтром.  
Футер: Контакты, ссылки на соцсети, политика конфиденциальности.  

## Страница: Аутентификация (/auth/*)
Тип доступа: Публичный (доступен только неавторизованным)  
Основные блоки:  
Страница входа (/auth/login)  
Страница регистрации (/auth/register)  

## Страница: Каталог (/catalog)
Тип доступа: Публичный  
Основные блоки:  
Боковая панель (Фильтры): Слайдер цены, чекбоксы по рекомендуемому возрасту, чекбоксы по производителям.  
Динамика: При изменении любого параметра отправляется запрос  
Центральная область:  
Верхняя панель: Сортировка (по цене, по новизне), количество товаров на странице (40).  
Сетка товаров (Grid): Карточки (изображение, название, цена, рейтинг, кнопка "В избранное").  
Пагинация: Номера страниц внизу.  

## Страница: Детальная страница (/catalog/:id)
Тип доступа: Публичный  
Основные блоки:  
Галерея: Основное изображение + миниатюры (Thumbnails).  
Блок информации: Название, цена, рейтинг, кнопки "В корзину" / "В избранное".  
Таблица характеристик:  
Динамика: Данные приходят.  
Вкладки (Tabs): Описание, Отзывы, Доставка.  
Состояние загрузки: Скелетон (Skeleton) для текста и изображений.  

## Страница: Ошибка (/err)
Тип доступа: Публичный  
Основные блоки:  
Состояние ошибки: Блок с текстом "Не удалось загрузить. Проверьте подключение." и кнопкой "Повторить попытку подключения".  

## Страница: Избранное (/fav)
Тип доступа: Приватный (только для авторизованных)  
Основные блоки:  
Заголовок: "Любимки"  
Сетка избранных товаров:  

## Страница: Личный кабинет (/prof)
Тип доступа: Приватный (только для авторизованных)  
Основные блоки:  
Боковое меню.

## Схема данных и API:
User: class User(Base):  
    __tablename__ = "users"  
    ```
    id = Column(Integer, primary_key=True, index=True)  
    email = Column(String(255), unique=True, nullable=False, index=True)  
    password = Column(String(255), nullable=False)  
    name = Column(String(100))  
    role = Column(Enum(Role), default=Role.USER)  
    created_at = Column(DateTime(timezone=True), server_default=func.now())  
    updated_at = Column(DateTime(timezone=True), onupdate=func.now())  
    ```
    
Избранное: class Favorite(Base):  
    __tablename__ = "favorites"  
    ```
    user_id = Column(Integer, ForeignKey("users.id"), primary_key=True)  
    toy_id = Column(Integer, ForeignKey("toys.id"), primary_key=True)  
    created_at = Column(DateTime(timezone=True), server_default=func.now())  
    ```
